# Job Description: Senior Full Stack Developer

## Project Overview

We are building a high-performance Telegram bot and web interface dedicated to trading on Polymarket. Our
mission is to provide traders with the fastest, most reliable execution tools in the prediction market space. We
are looking for a Senior Developer who lives and breathes code, understands the nuances of DeFi, and can
architect systems that don't sleep.

## Key Responsibilities

- Build and maintain performant, reliable cross-venue trading execution systems (Polymarket, Kalshi).
- Take full ownership of securing the stack and ensuring 99.9% uptime.
- Collaborate on API design, develop responsive frontends, and integrate complex backend logic.
- Shave off every possible millisecond from the frontend to the execution stack.
- Manage deployment pipelines and cloud infrastructure on AWS/Linux.

## Technical Requirements

- Python (Senior/Expert): Async programming & backend architecture.
- Database: Postgres with tortoiseORM.
- API Mastery: REST, WebSockets, and gRPC.
- Frontend: TypeScript, NextJS, HTML5, CSS3.
- Infrastructure: AWS, Linux administration, and DevOps.
- **Language: Professional working proficiency in English (Mandatory).**

## Preferred Experience

- Worked on Trading Systems (Crypto or TradFi).
- Experience with on-chain data and Smart Contracts.
- Designed robust, scalable distributed systems.
- Experience in Startups and managing small teams.
